# Hospital Emergency Room Dashboard (Interactive Dashboard using MS Excel)
## Project Objective
The objective of this project is to analyze Hospital Emergency Room data and build an interactive Excel dashboard that provides meaningful insights into patient flow, hospital performance, and operational efficiency. The dashboard helps healthcare professionals monitor key performance indicators (KPIs) and make data-driven decisions.
## Questions (KPIs)
How many patients were admitted vs. not admitted?
What is the average patient waiting time?
What is the patient satisfaction score?
What percentage of patients were attended within 30 minutes?
Which age group visited the emergency room the most?
What is the gender distribution of patients?
Which departments received the highest patient referrals?
How do patient visits vary by month and year?
## Process
Imported and cleaned the hospital dataset.
Removed duplicate and missing values.
Standardized data formats for accurate analysis.
Created Pivot Tables for KPI calculations.
Built Pivot Charts for data visualization.
Added Month and Year slicers for interactivity.
Designed KPI cards for quick performance monitoring.
Developed a fully interactive dashboard in Microsoft Excel.
